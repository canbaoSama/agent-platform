## Prompt

1. 长会话消息过多时，上下文太长会导致模型压力大并且不准确，如何让系统帮助模型管理记忆；
2. 为什么需要Prompt、Tool Schema、模型和 Eval 一起版本化；
3. 如何保证每次prompt的修改不会降低质量；
4. 如何避免Prompt Injection：文档或网页伪装成指令；
5. 如何解决摘要不断压缩后丢失事实和约束；
6. 如何优化我们的prompt。

## Tool

1. 工具过多时，如何实现Tool Retrieval,做到不把所有工具全部塞给agent；
2. 如何管理不同类别的工具，如何快速匹配工具；
3. 有副作用的工具和破坏性工具如何限制；
4. 并行调用工具或工具存在隐藏依赖时如何解决；
5. 工具的返回结果如何验证，如何保证工具的返回结果的正确率；
6. 如果一个工具存在人工审批这些不确定性时，如何处理。

## RAG

1. 离线和在线的设计模式有啥区别；
2. 能否支持每天定时发起在线更新，会不会影响性能；
3. 向量库过大的话如何增强检索能力；
